MyAthan USB flasher

Same firmware as GitHub esp8266-latest (currently v2.2.11). Use a USB cable. Phones will not work.

  1. Open this page in Google Chrome or Microsoft Edge on a Windows / Mac / Linux PC. Not Safari, not iPhone, not Android Chrome.
  2. Plug the MyAthan box into USB. On Windows, install the CH340 driver if Windows does not show a COM port.
  3. Click Connect below. Pick the USB / CH340 / UART port (not Bluetooth). Pair / allow access if Chrome asks.
  4. Install firmware. If it asks Erase device, leave that unchecked on a box that was already set up. Wi‑Fi, prayer offsets, calculation method, location, and volume stay. Only check erase for a factory wipe.
  5. Wait until it finishes, then unplug and plug the box back in.
  6. You should not need to enter Wi‑Fi again. If MyAthan Setup appears, join it (no password). The setup page should open by itself; if not, try http://192.168.4.1 or http://myathan.local. After it joins home Wi‑Fi, use http://myathan.local on the same network.
This browser cannot flash over USB. Open this page in Chrome or Edge on a computer. USB flashing only works on https:// (or localhost). Use the GitHub Pages link, not a raw file.

If the port list is empty, try another USB cable (data, not charge-only) and a USB-A port on the PC.
